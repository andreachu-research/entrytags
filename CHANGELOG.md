# Changelog

## 1.6.0 - 2026-10-01

- Package `tagpreview` and `taggenerate` for installation with Stata's
  `net install` command.
- Support one to ten tagged source variables and one to ten extracted
  attributes.
- Add `keep()`, `saving()`, and `replace` support to `taggenerate`.
- Preserve `EntryRem`, `OriginalCol`, and `EntryOriginal` in generated data.
- Make extracted date formatting portable across macOS, Linux, and Windows.
